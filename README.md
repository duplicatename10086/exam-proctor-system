# 监考系统（答题考核系统）

一个本地桌面端的答题考核系统，采用「母体 → 子体 → 报告」三层架构。白蓝主题界面，强防作弊，A 方案安全加固。

## 架构

```
母体（出题人）  ──生成──▶  子体（考生，独立 exe）  ──交卷──▶  只读成绩报告
  题库管理                    内置题目（答案已混淆）           Ed25519 签名
  考试配置                    计时 / 防作弊                    含题目/答案/作答附件
  一键生成子体                按关键词/答案摘要判分
```

- **母体**：出题工具，可视化录入题目（单选/多选/判断/填空/主观），配置考试，一键打包出考生客户端。
- **子体**：考生在本机运行的独立 exe，内置题目。流程：填写信息 → 抽题 → 计时答题 → 交卷 → 判分 → 生成报告。
- **题库**：以考试名称命名的文件夹（默认 `E:\题库\`），内含 `bank.json` 和 `media/` 附件。

## 功能

### 题型与判分
- 单选 / 多选 / 判断：答案精确比对（加固后比对 HMAC 摘要）
- 填空 / 主观：按关键词命中数量给分，支持近义词（用 `|` 分隔），可接 AI 接口给出评语

### 图片 / 视频附件（双向）
- 出题人：每道题可传「题目附件」和「答案附件」，题库文件夹统一放 `media/`
- 答题人：每道题可上传「作答附件」
- 报告里每题含：题干附件 + 参考答案附件 + 考生作答附件（base64 内嵌，只读 + 签名）

### 防作弊
- 全屏置顶、隐藏任务栏
- 全局键盘钩子屏蔽切换快捷键（Alt+Tab / Win 等）
- 反虚拟机检测（VMware / VirtualBox）
- 普通题阶段锁网，实操题阶段凭令牌恢复
- UAC 提权、关键进程保护
- 切屏 / 违规按键全程记录进报告
- 退出时自动恢复网络与键盘（交卷才放行网络）

### 安全加固（A 方案）
| 防护 | 实现 |
|---|---|
| 答案不明文 | 客观题答案、填空/主观关键词全部转 HMAC 摘要，子体不含明文答案 |
| 报告防伪造 | Ed25519 非对称签名，出题人持验签公钥 |
| 状态防篡改 | AES-GCM 加密，密钥绑定机器特征 |
| 计时防改 | `perf_counter` 单调时钟，改系统时间无效 |
| 网络令牌 | 恢复网络需输入出题人令牌，一次性 |
| AI Key 保护 | 不下发到子体 |

> **说明**：A 方案能挡住扒包看答案、改报告、改状态、改时间、白嫖网络、盗刷 key；但判分仍在考生本机，理论上可被逆向/暴破。正式考试建议把判分搬到服务端（B 方案）。

## 目录结构

```
proctor-system/
├── author_app.py       母体 UI
├── child_app.py        子体 UI（考生端）
├── build_mother.py     打包母体 exe
├── make_icon.py        生成图标
├── core/
│   ├── models.py       数据模型
│   ├── bank.py         文件夹化题库存储
│   ├── builder.py      子体生成器（加固边界）
│   ├── grader.py       判分（摘要比对 + 关键词）
│   ├── security.py     加固模块（摘要/签名/加密/令牌）
│   ├── storage.py      状态持久化 + 报告签名
│   ├── anticheat.py    防作弊模块
│   └── ui_theme.py     白蓝主题
└── assets/icon.ico     图标
```

## 使用

1. 运行母体：需要 Python 3.12 + `PyInstaller`、`cryptography`、`Pillow`、`requests`
   ```
   pip install pyinstaller cryptography pillow requests
   python author_app.py
   ```
2. 母体「题库管理」添加题目 → 「考试配置」设置 → 「保存题库」
3. 「生成子体」得到 `dist\监考系统.exe` + 若干「出题人…」敏感文件
4. **只把 exe 发给考生**，出题人文件自己保管：
   - `出题人答案对照表_请勿分发.json` — 明文答案，复核用
   - `出题人验签公钥_请妥善保管.pem` + `出题人验签工具.py` — 验报告
   - `监考令牌_请妥善保管.txt` — 考生恢复网络需报此令牌

## 依赖

Python 3.12，第三方库：PyInstaller、cryptography、Pillow、requests（tkinter 标准库自带）。
